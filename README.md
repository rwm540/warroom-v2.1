## 🎯 معرفی کلی پروژه
پلتفرم **«اتاق جنگ»** یک سامانه تعاملی مدرن به سبک بازی‌های استراتژیک (مشابه Clash of Clans و داشبوردهای فرماندهی تاکتیکی) است که برای هدایت مأموریت‌های کتاب‌خوانی، چالش‌های گروهی، تولید محتوای چندرسانه‌ای و ارتقای مهارت‌های نوجوانان طراحی شده است. کاربران در قالب جوخه‌ها و تیم‌های عملیاتی عضو شده، مراحل داستانی را پشت سر گذاشته، کریستال و امتیاز تجربه (XP) کسب کرده و برای دستیابی به ۹ جایزه رویایی و فتح سکوی قهرمانی به رقابت می‌پردازند.

---

## ✨ ویژگی‌ها و قابلیت‌های شاخص

### ۱. سیستم احراز هویت و امنیت هوشمند
* **ورود بر پایه کد ملی (National ID):** ورود مستقیم با کد ملی ۱۰ رقمی معتبر و رمز عبور.
* **بازیابی رمز عبور (Forgot Password):** پنجره تعاملی دومرحله‌ای جهت استعلام شماره ملی و تغییر آنی کلمه عبور.
* **تفکیک خودکار نقش‌ها:** ورود به عنوان رزمنده/فرمانده جوخه، بازرس یا مدیر ارشد عملیات (Admin).

### ۲. آموزش تعاملی فرمانده (Onboarding Tutorial)
* راهنمای گام‌به‌گام و دیالوگی به سبک بازی‌های استراتژیک با حضور فرماندهان هوشمند پویش.
* معرفی بخش‌های نقشه، جوایز، ویترین آثار و جدول رده‌بندی به کاربر با قابلیت رد کردن (Skip) یا رفتن به مراحل بعد.

### ۳. جلوه‌های بصری نئونی و رادار ۳۶۰ درجه
* پس‌زمینه تاکتیکی دارک‌مود همراه با اسکنر راداری چرخان (`radar-sweep`) و شبکه‌بندی مختصاتی.
* افکت‌های درخشان نئونی برای متن‌ها، حاشیه‌ها و نشان‌ها متناسب با هر جنسیت.

## 🎨 پویش‌ها و تم‌های بصری

این سامانه به صورت هوشمند دارای دو تم طراحی و هویت بصری است:
1. **پویش پسران (نوید - Navid):**
   * رنگ قالب: نئون فیروزه‌ای (`#22d3ee`) و سرمه‌ای تاریک تاکتیکی.
   * آیکون‌ها و المان‌های الهام‌گرفته از رادار، پایگاه‌های فضایی و فرماندهی نبرد.
2. **پویش دختران (سیندخت - Sindokht):**
   * رنگ قالب: رزگلد، ارغوانی و صورتی نئونی (`#f472b6`).
   * المان‌های الهام‌گرفته از بلورهای کیهانی، شوالیه‌های روشنایی و طراحی ارگونومیک نئونی.

## 🕹️ بخش‌های اصلی سامانه

| بخش | مسیر / Tab | شرح عملکرد |
| :--- | :--- | :--- |
| **نقشه مراحل بازی** | `Journey` | نقشه تاکتیکی جاده‌ای با مراحل قفل/باز، پیش‌نیازهای کریستالی و مرحله تپنده فعال |
| **جوایز و امتیازات** | `Rewards` / `Prizes` | گرید ۳×۳ شامل ۹ جایزه شاخص (Xbox، ساعت هوشمند، VR، تبلت، کوادکوپتر، هدفون و...) به همراه راهنمای ضرایب امتیاز |
| **ویترین و اکسپلور** | `Vitrin` | گرید اکسپلور چندرسانه‌ای آثار، قابلیت Double-Tap Like با قلب نئونی و امتیازدهی ۱ تا ۵ ستاره |
| **سکوی قهرمانی و رده‌بندی** | `Leaderboard` | پودیوم ۵ تیم برتر (سکوهای طلا، نقره و برنز) + جدول اسکرول‌شونده جوخه‌ها |
| **داشبورد عملیات** | `Dashboard` | خلاصه وضعیت جوخه، درصد پیشرفت، سطح (Level)، آمار تیمی و اعضای گروه |
| **پایگاه آموزش‌ها** | `Trainings` | ویدیوها، صوت‌ها و راهنماهای تاکتیکی دسته‌بندی‌شده برای مأموریت‌ها |
| **پنل مدیریت ارشد** | `Admin` | داشبورد پایش تیکت‌ها، بازبینی آثار ارسالی، تعریف مراحل جدید و مدیریت کاربران |

## 💻 پشته فناوری (Tech Stack)

* **هسته فرانت‌اند:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **موتور باندلینگ:** [Vite](https://vitejs.dev/)
* **استایل‌دهی:** [Tailwind CSS v4](https://tailwindcss.com/)
* **انیمیشن‌ها و ترنزیشن‌ها:** [Motion (Framer Motion)](https://motion.dev/)
* **مجموعه آیکون‌ها:** [Lucide React](https://lucide.dev/)
* **تقویم و تاریخ:** ابزار داخلی تبدیل تاریخ شمسی (Jalali) با قالب‌بندی ارقام فارسی
* **طراحی ریسپانسیو:** پشتیبانی دقیق و تست‌شده از دسکتاپ، تبلت و گوشی‌های هوشمند

## 🛠️ راهنمای نصب و راه‌اندازی

برای اجرای پروژه در محیط توسعه محلی، مراحل زیر را طی نمایید:

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. اجرای سرور توسعه (Dev Server)
```bash
npm run dev
```
برنامه بر روی پورت `3000` (آدرس `http://localhost:3000`) در دسترس خواهد بود.

### ۳. ساخت نسخه نهایی (Production Build)
```bash
npm run build
```

### ۴. تست و اعتبارسنجی تایپ‌ها (Lint)
```bash
npm run lint
```

## 📝 گزارش اقدامات و کارهای انجام‌شده (Changelog)

1. **طراحی و پیاده‌سازی صفحه ورود و ثبت‌نام با کد ملی:**
   - فیلد اختصاصی کدملی ۱۰ رقمی با ولیدیشن آنی.
   - سیستم کامل فراموشی رمز عبور دو‌مرحله‌ای.
   - حذف کامل متون اضافی و جایگزینی با لوگوی نئونی پالس‌دار.
2. **پیاده‌سازی نقشه راه بازی (Journey Map):**
   - طراحی نقشه تاکتیکی جاده‌ای با مراحل زنجیره‌ای.
   - استایل مرحله فعال با انیمیشن تپنده نئونی (`level-pulse`).
   - قفل بودن هوشمند مراحل آتی بر اساس کریستال‌های کسب‌شده.
3. **طراحی ویترین ۹ جایزه رویایی (Prizes & Points):**
   - گرید ۳×۳ از هدایای ارزشمند نوجوانان با تصاویر باکیفیت و درصد پیشرفت امتیاز.
   - تب راهنمای شفاف نحوه کسب امتیاز، ضرایب تیمی و جوایز مأموریت‌ها.
4. **توسعه ویترین آثار و اکسپلور (Vitrin View):**
   - رابط کاربری مشابه اینستاگرام برای مرور ویدیوها و تصاویر جوخه‌های سراسر کشور.
   - پیاده‌سازی قابلیت دبل‌تپ برای لایک با افکت قلب جهنده نئونی.
   - مدال نمایش تمام‌صفحه اثر و امتیازدهی ۱ تا ۵ ستاره توسط داوران و هم‌رزم‌ها.
5. **بازطراحی سکوی افتخار و رده‌بندی (Leaderboard Podium):**
   - سکوی سه‌بعدی ۵ تیم برتر (طلایی، نقره‌ای، برنزی) با نشان تاج و بال.
   - جدول تفکیکی رتبه‌های بعدی با قابلیت جستجو بر اساس شهر و جوخه.
6. **پیاده‌سازی آموزش تعاملی فرمانده (Onboarding Tutorial):**
   - دیالوگ‌باکس‌های گیمینگی با آواتار فرمانده جهت راهنمایی کاربر تازه وارد.
7. **بهینه‌سازی کامل استایل‌ها و رادار:**
   - انیمیشن چرخش رادار ۳۶۰ درجه و لایه‌بندی پس‌زمینه بدون افت فریم.
   - سازگاری ۱۰۰٪ راست‌چین (RTL) و فونت‌های استاندارد فارسی.
